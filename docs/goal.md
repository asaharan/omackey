# Goal

The goal of this plugin is to make Omarchy feel like macOS, with an emphasis
on navigation and familiar application shortcuts.

1. `Super+Tab` and `Super+~` switch between windows.
2. `Super+T` opens a new tab and `Super+Shift+T` reopens a closed tab.
3. `Super+Q` closes the window.
4. `Super+W` closes the current tab or document.
5. `Super+Backspace` deletes to the start of the line.
6. `Super+Left` and `Super+Right` move to the start and end of the line.
7. `Ctrl+Left` and `Ctrl+Right` focus the window in that direction, including
   across monitors and when full-width or fullscreen windows obscure others.
8. Common macOS application shortcuts use `Super`: select all, undo/redo,
   find, save, open, print, new window, reload, focus location, back/forward,
   and next/previous match.
